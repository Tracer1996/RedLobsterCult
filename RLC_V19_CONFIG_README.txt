CONFIG MODE
/config              Toggle config mode
/config unlock       Enter config mode
/config save         Save positions and lock the layout
/config dump         Print all registered coordinates in chat
/config reset        Reset all positions
/config lock         Lock config mode

Config mode creates draggable overlays for navigation buttons, main content areas,
Dossier sections, character model frame, Recent Badges, Achievements, action buttons,
Raise the Claw, and the close button.

Positions are saved per character in RLC_DB.layoutEditor.positions.
